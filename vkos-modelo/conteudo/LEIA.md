# 📱 Conteúdo: tudo que o VKOS cria fica aqui

Cada peça que você gera (carrossel, stories, semana de conteúdo, página) é salva aqui
dentro, numa subpasta própria.

## Como fica organizado

O VKOS cria uma subpasta pra cada peça, com data e tema no nome, assim:

```
conteudo/
  2026-07-01-cinco-erros-no-instagram/
    carrossel.html            → a peça montada
    instagram/                → as imagens prontas pra postar (slide-01.png, slide-02.png...)
    legenda.md                → a legenda pra colar no Instagram
  2026-07-03-oferta-da-semana/
    ...
```

Assim você sempre acha o que criou, na ordem em que criou. Nada se perde.

> Você não precisa mexer aqui na mão. Os comandos criam e organizam as pastas sozinhos, e sempre
> te avisam o caminho onde salvaram. Quando quiser postar, é só abrir a subpasta da peça.
