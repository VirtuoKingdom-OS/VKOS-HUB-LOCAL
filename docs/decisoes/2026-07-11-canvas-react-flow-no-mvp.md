# Canvas React Flow desde o MVP

## Contexto
O roadmap deixava o canvas visual pra fase 3, depois de uma lista simples. O Jesse revisou o escopo: o valor central do produto é enxergar as gerações e conectar ideias com facilidade.

## Decisão
React Flow (@xyflow/react) entra desde o MVP. O Cérebro é o nó central do canvas e as sessões de IA são nós que puxam dele.

## Por quê
O workspace visual é o produto, não um enfeite de fase futura. Sem o canvas o MVP não valida a tese. React Flow entrega nós, arestas, zoom e pan prontos, sem construir canvas do zero.
